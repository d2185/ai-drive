# Smarta AI — программа сетевого диска для Windows

Программа синхронизации Nextcloud Desktop под нашим именем: папка «Smarta AI» в Проводнике, файлы по требованию
(Windows Cloud Files API), сервер — `drive.ai.unert.com` (чат Smarta AI, `serve.py` класс `Cloud` в
[ai-server](https://github.com/d2185/ai-server)).

- `brand.py` — имя, иконка, сервер, свои GUID, без самообновления, одна учётная запись с виртуальными файлами;
- `patches/` — правки исходников (по порядку номеров): своих окон нет ни в одном случае — значок у часов (без меню)
  открывает «Профиль → Сетевой диск» на сайте, а пока компьютер ждёт подтверждения — его «Подключить»; нет мастера,
  всплывающих сообщений, окон ошибок файла, сертификата, прокси, звонков, импорта чужих учётных записей и сокета для
  чужих программ; отключённый компьютер не показывает окно входа, а сам открывает «Подключить» в браузере и ждёт;
  компьютер, отключённый в профиле, получает удалённую очистку: программа стирает папку и учётную запись и удаляет себя
  (диск S:, автозапуск); после каждой смены состояния программа сообщает его серверу (`/ocs/v2.php/apps/smarta/status`);
  пауза между синхронизациями не больше секунды; свои файлы в папке — скрытые и системные;
- значок в трее — наш логотип: синий (#00A0E3), пока диск работает, красный, когда нет (`brand.py` красит state-*.svg);
- `theme/logo.svg` — иконка (логотип чата);
- `.github/workflows/build.yml` — сборка на GitHub (KDE Craft, как у Nextcloud). Тег `v<версия>-<n>` выкладывает
  `smarta-ai-<версия>-windows-x64.7z` и `SHA256SUMS` в релиз; установщик с подключением по коду из профиля собирает
  `install.sh` сервера AI.

Новая версия Nextcloud: поменять `VERSION` в `build.yml`, поставить тег. Если `brand.py` не нашёл свою строку,
сборка остановится на нём — поправить замену.
